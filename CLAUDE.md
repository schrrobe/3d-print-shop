# Claude Code workflow

Before non-trivial implementation work, create or update
`docs/agent-handoff/current-plan.md` with the active goal, context, likely file
changes, implementation steps, test plan, risks or assumptions, and open
questions.

# Git authorship

Commits and pull requests carry only the user (Robert) as author. Never add
Claude as author or co-author: no `Co-Authored-By: Claude` trailer in commit
messages, no "Generated with Claude Code" line in PR descriptions, no other
Claude attribution.
