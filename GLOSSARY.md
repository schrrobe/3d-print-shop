# Print Shop

Online-Shop für 3D-gedruckte Produkte: Bestellung, Produktion und Versand.

## Versand

**Sendung**:
Ein Paket an den Kunden mit einer Teil- oder der Gesamtmenge der Positionen einer Bestellung.
_Avoid_: Lieferung, Paket (als Fachbegriff)

**Versandnummer**:
Die interne Kennung einer Sendung (`VER-2026-00001`).
_Avoid_: Sendungsnummer (für die interne Nummer)

**Sendungsnummer**:
Die vom Versanddienstleister vergebene Nummer, unter der der Kunde sein Paket verfolgt.
_Avoid_: Trackingnummer, Paketnummer

**Versanddienstleister**:
Das Unternehmen, das die Sendung transportiert (DHL oder Hermes); wird intern gewählt, nie vom Kunden.
_Avoid_: Carrier, Paketdienst

**Versandlabel**:
Das beim Versanddienstleister erzeugte Etikett mit Sendungsnummer, das auf das Paket geklebt wird.
_Avoid_: Paketschein, Etikett, Label
