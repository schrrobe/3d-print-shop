# Glossar

## Bestellung

**Rechnungsadresse**
Name, Firma und Anschrift, die der Kunde beim Kauf angibt. Sie steht auf der
Rechnung und ändert sich danach nicht mehr.
_Vermeiden_: Kundenadresse, Adresse (ohne Zusatz)

**Lieferadresse**
Abweichender Empfänger und Anschrift, an die die Ware geht. Optional; ohne
Lieferadresse wird an die Rechnungsadresse geliefert. Nur bis zum Versand
änderbar.
_Vermeiden_: Versandadresse, Zustelladresse

## Versand

**Sendung**
Ein Paket an den Kunden mit einer Teil- oder der Gesamtmenge der Positionen
einer Bestellung.
_Vermeiden_: Lieferung, Paket (als Fachbegriff)

**Versandnummer**
Die interne Kennung einer Sendung (`VER-2026-00001`).
_Vermeiden_: Sendungsnummer (für die interne Nummer)

**Sendungsnummer**
Die vom Versanddienstleister vergebene Nummer, unter der der Kunde sein Paket
verfolgt.
_Vermeiden_: Trackingnummer, Paketnummer

**Versanddienstleister**
Das Unternehmen, das die Sendung transportiert (DHL oder Hermes); wird intern
gewählt, nie vom Kunden.
_Vermeiden_: Carrier, Paketdienst

**Versandlabel**
Das beim Versanddienstleister erzeugte Etikett mit Sendungsnummer, das auf das
Paket geklebt wird. Es trägt die Lieferadresse.
_Vermeiden_: Paketschein, Etikett, Label
